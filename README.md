# מערכת תורנויות בית הספר

גרסה ללא Google Cloud וללא OAuth.

האפליקציה קוראת את התורנויות מ-Apps Script ומייצרת קובץ יומן אחד עבור המורה שנבחר.
בפתיחת הקובץ מערכת היומן במכשיר מאפשרת לייבא את האירועים ליומן קיים.

לכל יום תורנות:
- 08:00 — תזכורת בוקר
- 10:20–10:35 — התראה 10 דקות לפני
- 12:10–12:35 — התראה 10 דקות לפני

העלו את שלושת הקבצים index.html, style.css, app.js ל-GitHub Pages.
