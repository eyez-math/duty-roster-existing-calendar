# תורנויות בית הספר – גרסה ללא Apps Script

האתר קורא ישירות מה-Google Sheet שפורסם באינטרנט.
אין צורך בהתחברות לחשבון Google כדי לראות את רשימת המורים.

מקור הנתונים:
- שבוע 1
- שבוע 2
- חופשות

שינויים בטבלה המפורסמת ייקראו מחדש בטעינת האתר (בכפוף לזמן העדכון של Google בפרסום).

העלאה ל-GitHub Pages: index.html + style.css + app.js.
